# Brain Train

A trivia train ride: answer right and the train moves to the next station. English or Tagalog.

- Version: 1.7 (phone layout fits one screen). Made by us, with the mascot Choo-Choo Noodle.
- `index.html`: the whole game, one page. Sent byte-for-byte at kalendaryo.co/brain-train. Do not edit it here.
- `tile-icon.svg`: Choo-Choo Noodle, drawn for the Games page tile (put inline in the tile).
- Fonts: Lilita One and Nunito from Google Fonts (SIL Open Font License).
- Saves only in this browser (localStorage). No login, no family data.
- Inside Kalendaryo, the page notices it is in a frame (`body.framed`) and lets Kalendaryo's background show through.

To use it on another website: copy this folder and open `index.html`.
