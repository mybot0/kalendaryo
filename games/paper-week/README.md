# Paper Week

Fly a paper plane through the week: tap to glide past the pages. English or Tagalog.

- Version: 2.2 (a 2D paper-plane game). Made in our "Interactive Games for Kids" project.
- `index.html`: the whole game, one page, 136,049 bytes.
  SHA-256 a79634a9a64c0398996bf4ef8cb96b686516dd6761994783bb13de25dcb1cf6c. Sent byte-for-byte at kalendaryo.co/paper-week.
  Do not edit, reformat or minify it here.
- Icons: `paper-week-icon.svg` (the Games page tile), `paper-week-icon-192.png`, `paper-week-icon-512.png`.
- Fonts: Outfit and Figtree (SIL Open Font License), inside the page as data: URLs; the licence texts are inside the file.
- Makes no network requests. Saves only in this browser (localStorage, keys starting with "dayglider:"). No login.

To use it on another website: copy this folder and open `index.html` (allow data: fonts if the site has a strict CSP).
